# Agent Pack Canonical Foundation

## Priority

P0. Start now, in parallel with `todo.agent-guidance-baseline`.

## Purpose

Land the mechanical single-source foundation from
`dec.agent-pack-packaging` before editing rendered guidance. This is phase one
of the ratified eight-clause contract. The Claude bootstrap and OMP adapter
todos complete the remaining lifecycle and live-adapter obligations.

## Scope

- Create the canonical harness-neutral pack source and pack manifest.
- Represent per-harness structural differences as pure adapter rows in data.
- Support addressing canonical prompt assets by a logical entry id plus
  explicit mode, but assign no current authority to a new mode in this
  foundation. The lookup carries no scheduler, state machine, or workflow
  edges.
- Add a dev-only renderer. Generated output remains compiled through
  `include_str!`; the renderer is not shipped in the user CLI.
- Make this repository's Claude Cairn pack rendered output and enforce
  byte-for-byte drift.
- Keep generated markers out of content. Use manifest enumeration plus
  `.gitattributes linguist-generated`.
- Preserve the dev-repo boundary: hand-authored development content is touched
  only where the pack manifest owns generated Cairn paths.

## Claude foundation contents

The first rendered set preserves the current `cairn-dev`, `cairn-explore`,
`cairn-propose`, `cairn-apply`, and `cairn-archive` content plus Claude's
`/cairn-loop`, recovery, and landing assets byte for byte. This is a mechanical
migration baseline and creates no new authority.

After the required refining decision,
`todo.agent-guidance-router-playbooks` makes `cairn-dev` the single logical
entry, remaps the native loop command as adapter transport for explicit loop
mode, and adds the required scope and implement procedures before revised
guidance is evaluated.

## Deterministic validation

- Require exactly one producer for each normalised emitted destination and
  logical entry-mode pair.
- Reject lexical path escapes during rendering.
- Provide the shared resolved-path and symlink-containment validation that the
  installer preflight will apply, reusing the `wire.rs` safety pattern.
- Diagnose the adapter row, conflicting producer, or escaping path and give the
  corrective action.

The canonical and installed ownership manifests remain file ownership ledgers.
They never gain semantic workflow or orchestration schemas. Harness-native
formulas and runtime configuration live in external adapter surfaces.

## Acceptance

- Renderer output is deterministic and byte-identical to checked-in generated
  files.
- A negative collision case and path-escape cases fail with actionable
  diagnostics.
- All current pack consumers compile from the rendered bytes.
- The split foundation plus Claude bootstrap and OMP adapter jointly preserve
  every clause of `dec.agent-pack-packaging`.

## Dependencies

None. The contract is ratified and no active change owns this scope.
