# Design: agent-guidance-provenance

## Approach

Author the complete Source -> Research -> proposed Decision chain as a
provenance-only unit. The external anthology is advisory mechanism evidence.
Accepted local decisions remain the authority for semantic versus runtime
ownership. The refining decision changes only the conditional future canonical
location of the one-iteration procedure. Owner acceptance later sanctions
`todo.agent-guidance-router-playbooks` to implement the migration; standalone
`/cairn-loop` remains normative until that later cutover lands.
