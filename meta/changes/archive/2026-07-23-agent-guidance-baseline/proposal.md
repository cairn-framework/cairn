# Proposal: agent-guidance-baseline

## Motivation

The agent-guidance programme needs a causal baseline before its router, pack, or proof units change shipped guidance. Existing observations do not isolate the query surface from the guidance pack.

## Scope

- Compare target-only navigation, the Cairn query surface, and the current Cairn guidance pack.
- Use frozen read-only tasks from two external repositories.
- Preserve run records, blinded grading, failures, and final analysis.
- Record only reversible follow-up hypotheses.

## Out of scope

- Implementing a router, pack, query, or runtime change.
- Opening the sealed confirmation split.
- Treating corrected engaged runs as replacements for the failed primary cohort.
