# mattpocock/skills: Skills for Real Engineers

Matt Pocock's public skill collection (MIT, ~207k stars at read time), read
2026-08-07 at the maintainer's prompt. Files read in full:
`skills/productivity/writing-for-agents/SKILL.md`, `wait-what/SKILL.md`,
`handoff/SKILL.md`, `to-questionnaire/SKILL.md`,
`skills/engineering/diagnosing-bugs/SKILL.md`, plus the repository README and
full listing.

Position stated in its README: small, composable, model-agnostic skills that
fix four failure modes (misalignment, verbosity, broken feedback loops,
architectural entropy), explicitly against process-owning frameworks. Its
`grill-with-docs` centres a `CONTEXT.md` ubiquitous-language file and ADRs;
its `diagnosing-bugs` is a six-phase gated loop whose phase 1 completion
criterion is a named, already-run, red-capable command; `writing-for-agents`
is a compact theory of agent-directed documents: context pointers, the two
loads (context and cognitive), an information hierarchy with progressive
disclosure as its protection, steps ending on completion criteria (premature
completion as the named failure), leading words over restatement, positive
phrasing over negation, and pruning tests (single source of truth, cache,
sediment, no-op).

Consumed by `res.skill-absorption`, which maps each technique to a
cairn-native adoption point. No third-party skill is installed into this
repository; techniques are absorbed into cairn's own artefacts or declined.
